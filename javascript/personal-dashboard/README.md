# Personal Study Dashboard

Not pretty. Functional.

Goal:

Build a browser-based dashboard around actual routines while consolidating JavaScript fundamentals through small, useful features.

Estimated duration:

**3–5 days**

Rules:

```txt
NO React
NO Tauri
NO TypeScript
NO Cursor
NO ChatGPT code
```

Allowed:

```txt
MDN
Google
Error messages
Documentation
```

---

## Features

```txt
Home
├── Today's focus
├── Study timer
├── Mood / energy slider
├── Task list
├── Calendar
├── Daily notes
└── Streak counter
```

## Allowed Debugging Workflow

Correct:

```txt
Error message
↓
Read
↓
Understand
↓
Fix
```

Incorrect:

```txt
Paste full file into AI
↓
Receive architecture transplant
↓
Temporary understanding
```

## Success Criteria

When finished, you should be able to explain:

```txt
What state is

What rerendering means

How localStorage works

What event listeners do

How DOM manipulation works

Why null errors happen

Why IDs matter

How data flows through an app
```

Goal:

Move from:

> "I can't do JS"

to:

> "I can build small frontend applications."

That difference is much larger than syntax.

---

## Final Rule

Build first.

Get stuck.

Debug.

Repeat.

Understanding forms during the struggle, not after receiving the solution.
