Project: Personal Dashboard

Goal:
Build a personal browser dashboard that tracks study habits, tasks, reminders, mood, and daily focus while gradually learning JavaScript fundamentals through real features.

Estimated time:
Several iterations (built feature-by-feature)

Difficulty:
Beginner → Intermediate frontend

Focus:
DOM manipulation, localStorage, state, events, rendering, Date objects, UI logic

Project description:

Orbit Dashboard is a personal life dashboard designed around my own routines as a CS + Math student. Instead of following tutorials, the project grows through small modules tied to actual use cases: planning assignments, tracking study sessions, organizing reminders, and monitoring habits.

The dashboard acts as both a practical tool and a JavaScript learning environment, where each feature introduces a new concept.

Possible modules:

Calendar
- Navigate months
- Save notes/reminders to dates
- Highlight important days
Concepts:
Date(), rendering, localStorage

Task / Reminder Panel
- Add tasks
- Delete tasks
- Mark complete
Concepts:
arrays, objects, events

Focus Timer
- Study timer
- Break timer
- Session tracking
Concepts:
setInterval(), state

Daily Check-in
- Mood
- Energy level
- Notes
Concepts:
forms, persistence

Study Streak Tracker
- Consecutive productive days
Concepts:
date comparison, logic

Quote / Motivation Widget
- Random quote
- Personalized messages
Concepts:
APIs, fetch()

Goals:
- Become comfortable building with vanilla JavaScript
- Learn frontend architecture through iteration
- Build useful tools around real habits instead of tutorial projects
- Understand data flow, state, and persistence
- Reduce dependence on AI-generated code over time

Current philosophy:
Build small → understand → refactor → expand
